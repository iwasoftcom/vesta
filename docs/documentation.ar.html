Vesta
تخزين كائنات متوافق مع S3 يسدّ الثغرات · الإصدار 0.1.0

نظام تخزين كائنات طبقي متوافق مع S3، مكتوب بلغة Rust — ملف تنفيذي واحد يتوسّع من حاسوب محمول إلى عنقود مُكرَّر عبر Raft، دون الحاجة لتغيير البرمجية.

ما هو Vesta

يستهدف Vesta الثغرات الوظيفية الموجودة في حلول تخزين الكائنات الحالية (S3، GCS، Azure Blob، R2، B2، Wasabi، MinIO، Ceph، SeaweedFS، Garage). يتحدّث واجهة S3 الحقيقية — توقيع SigV4، التحميل متعدد الأجزاء، الإصدارات، الطلبات الشرطية، الحذف الجماعي — ويفصل تمامًا بين مستوى التحكم (البيانات الوصفية: الدِلاء، فهرس الكائنات، إدارة الهوية) ومستوى البيانات (الكتل المخزّنة على القرص والمعنونة بالمحتوى)، بحيث يمكن استبدال كل منهما أو توسيعه بشكل مستقل.

مبادئ التصميم

الفصل بين مستوى التحكم ومستوى البيانات.
تعيش البيانات الوصفية والبايتات خلف حدود trait منفصلة. يمكن استبدال محركات التخزين وخلفيات الإجماع وطبقات التشفير دون المساس بطبقة واجهة S3.
لا يبقى أي مفتاح إداري منسيًا في ملف إعداد.
تحديد المعدل، فترات تنظيف الكتل (GC)، CORS، الحصص والسياسات كلها إعدادات زمن-تشغيل — تُكرَّر وتُعدَّل حيًّا من لوحة الإدارة، وليست متغيرات بيئة تتطلب إعادة تشغيل.
التوافق عقد، لا تقريب.
يُختبر SigV4 (الترويسات، روابط URL الموقّعة مسبقًا، الأجزاء المتدفّقة)، والتحميل متعدد الأجزاء، والإصدارات، والطلبات الشرطية باستمرار مقابل مجموعات اختبار حقيقية من SDK الخاص بـ AWS، لا أمثلة مُنتقاة يدويًا.

بداية سريعة

شغّل الخادم (صورة حاوية، أو الملف التنفيذي المستقل):

# Docker
docker run -p 9000:9000 iwasoftcom/vesta:0.1.0

# أو الملف التنفيذي
VESTA_DATA_DIR=/var/lib/vesta VESTA_ACCESS_KEY=AKIDEXAMPLE VESTA_SECRET_KEY=secret vesta

تواصل معه باستخدام أي عميل S3:

aws --endpoint-url http://127.0.0.1:9000 s3 mb s3://photos
aws --endpoint-url http://127.0.0.1:9000 s3 cp ./x.jpg s3://photos/x.jpg
aws --endpoint-url http://127.0.0.1:9000 s3 ls s3://photos

ما بداخله

تحديد المعدل
دلو رموز لكل مستأجر، يُفعَّل ويُضبَط حيًّا من لوحة الإدارة؛ العميل المسيء يحصل على استجابة SlowDown نظيفة، لا اتصالًا مقطوعًا.
الإجماع الموزَّع
Raft عبر الشبكة بانتخاب قائد، وعضوية ديناميكية، وتكرار دائم للسجل — أو اختر openraft، وهو تطبيق مُثبَت، خلف مسار الكتابة ذاته.
ترميز المحو والتشفير
تخزين مُرمَّز بالمحو بطريقة Reed–Solomon وتشفير AES-256-GCM أثناء الخزن، وكلاهما آمن مع إزالة التكرار (كتل معنونة بالمحتوى).
الإصدارات وقفل الكائن
سجل إصدارات كامل، علامات حذف، واحتفاظ WORM (GOVERNANCE/COMPLIANCE) مع حجز قانوني.
تعدد المستأجرين
المستأجرون كيان أساسي: حصص دِلاء لكل مستأجر، عزل هوية عبر SigV4، سياسات الدِلاء وقوائم تحكم وصول جاهزة.
البحث و Select و Lambda
بحث أصلي في البيانات الوصفية بفهرس معكوس، و S3 Select (SQL على CSV)، وتحويل عند القراءة (على طراز Object Lambda).
التكرار والأحداث
تكرار جغرافي غير متزامن، ناقل أحداث لتدفق التغييرات، وتسليم إشعارات عبر webhook قابل للتوصيل.
دورة الحياة والجرد
قواعد انتهاء الصلاحية والانتقال بين فئات التخزين، إضافة إلى تقارير جرد بصيغة CSV عند الطلب.

لوحة الإدارة

تطبيق إداري منفصل وعديم الحالة (واجهة React + MUI مدمجة) يُمرِّر عمليات الكتابة إلى عقد العنقود — لا يحتفظ ببياناته الخاصة؛ كل تغيير يُكرَّر عبر سجل الإجماع نفسه الذي تستخدمه واجهة S3. من خلاله يمكنك:

  • المستخدمون والمفاتيح والمستأجرون — حسابات اللوحة، مفاتيح API عبر SigV4، حصص لكل مستأجر.
  • الدِلاء والسياسات — الإنشاء/الحذف، JSON لسياسة الدلو، مفاتيح القراءة العامة.
  • العنقود — سلامة العقد، إضافة/إزالة الأعضاء، مفاتيح الكتابة بالأقلية والتقليص التلقائي.
  • إعدادات زمن التشغيل — تحديد المعدل، فترة تنظيف الكتل، أصل CORS: تُعدَّل حيًّا، وتُكرَّر على كل عقدة، وتبقى دائمة عبر إعادة التشغيل.

البنية

ملف تنفيذي واحد، بابان شبكيّان، وقاعدة طبقية صارمة: طبقة واجهة S3 لا تلمس التخزين مباشرة أبدًا — كل شيء يمرّ عبر المنسّق، وكل تغيير يجب أن يسري على مستوى العنقود بأكمله يمرّ عبر سجل الإجماع قبل أن يصبح مرئيًا لعملية قراءة.

التنزيلات والمصدر

  • التنزيلات: الملفات المُصرَّفة (Windows، Debian .deb، RedHat .rpm) وصورة Docker تُنشَر لكل إصدار على iwasoft.com ← المنتجات ← Vesta. الشيفرة المصدرية ليست جزءًا من التنزيلات.
  • التوافق: واجهة S3 (SigV4، متعدد الأجزاء، الإصدارات، الطلبات الشرطية) تُختبر باستمرار مقابل اختبارات تكامل حقيقية لـ SDK الخاص بـ AWS.
  • حالة صادقة: المشروع في مرحلة تطوير مبكرة — لم يخضع بعد لتدقيق أمني مستقل، ولا توجد بعد خبرة تشغيل إنتاجي. هذه إفصاحات، لا تحفظات على خارطة الطريق.
