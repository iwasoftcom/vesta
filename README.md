# Vesta

Enterprise object storage — S3-compatible and scalable.

> Enterprise software by **iwasoft** — product page: https://iwasoft.com/products/vesta

## What is Vesta?

Vesta is an S3-compatible object storage solution that runs in your own data center. It scales horizontally to petabytes, with versioning, lifecycle and replication management.

**Highlights**

- S3-compatible API
- Horizontal scaling to petabytes
- Multi-region replication
